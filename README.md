# ASP.NET Core RESTful API

This repository contains my practice projects for building RESTful APIs
using C#, ASP.NET Core Web API, Entity Framework Core, and SQL Server.

## 🚀 Technologies Used

- C#
- ASP.NET Core Web API
- RESTful API
- Entity Framework Core
- SQL Server
- LINQ
- Swagger / OpenAPI
- Postman
- Visual Studio

## 📚 Topics Covered

- Introduction to ASP.NET Core Web API
- RESTful API Architecture
- Controllers and Action Methods
- HTTP Methods (GET, POST, PUT, DELETE)
- Attribute Routing
- CRUD Operations
- Dependency Injection
- Model Binding and Validation
- Entity Framework Core
- Database Connectivity with SQL Server
- LINQ Queries
- JSON Request and Response Handling
- HTTP Status Codes
- Swagger API Documentation
- API Testing with Postman
- Exception Handling
- Asynchronous Programming with async/await

## 🎯 Project Objectives

- Learn RESTful API development using ASP.NET Core.
- Implement CRUD operations with SQL Server.
- Understand API routing and HTTP methods.
- Practice database operations using Entity Framework Core.
- Test and document APIs using Postman and Swagger.
- Strengthen backend development skills for .NET Full Stack Development.

## ⚙️ Getting Started

1. Clone this repository.
2. Open the solution in Visual Studio.
3. Update the SQL Server connection string in `appsettings.json`.
4. Restore the required NuGet packages.
5. Apply database migrations if required.
6. Run the application.
7. Test the endpoints using Swagger or Postman.
